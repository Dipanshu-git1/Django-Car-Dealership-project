# Contact Us page upload

This folder contains a `Contact.html` page for the Django Car Dealership capstone.

## Upload to GitHub

Upload the `Contact.html` and `site.css` files into this directory in your repository:

`server/frontend/static/`

The HTML links to `site.css` in the same directory. If your repository already has a `site.css`, compare it before replacing it.

**Demo data:** The email addresses use `example.com` placeholders. Replace them with the correct project contact details before submitting if required. The images are loaded from Unsplash and therefore need an internet connection.
